# Master Lovable Prompt — Brows & Bloom Aesthetic Clinic Website

Create a **high-end, fully responsive, modern website** for a premium permanent makeup and micropigmentation brand called:

# BROWS & BLOOM

### Aesthetic Clinic

Use the uploaded **Brows & Bloom logo** as the official brand logo. Do not redesign, replace, distort, crop, or generate a different logo.

The website should feel like a combination of:

**Luxury beauty editorial × premium aesthetic studio × modern medical-grade trust × high-conversion clinic website.**

The website must be visually polished, spacious, elegant, feminine but not childish, highly responsive, and conversion-focused.

Do NOT use excessive pink gradients, glitter, beauty stickers, cheap icons, excessive rounded cards, or generic salon aesthetics.

* Permanent Makeup
* Cosmetic Micropigmentation
* Scalp Micropigmentation
